### 📦 Приклади коду

#### `jikanpy` + API-запит:

```python
from jikanpy import Jikan

jikan = Jikan()
top_anime = jikan.top(type='anime')
print(top_anime['data'][0]['title'])
```

#### Вивід:

```text
<< Fullmetal Alchemist: Brotherhood >>
```

#### Flask-додаток:

```python
from flask import Flask
import requests

app = Flask(__name__)

@app.route("/")
def home():
    response = requests.get("https://api.jikan.moe/v4/top/anime")
    data = response.json()
    return f"<h1>{data['data'][0]['title']}</h1>"

if __name__ == "__main__":
    app.run(debug=True)
```
